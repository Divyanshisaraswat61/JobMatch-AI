# JobMatch AI

AI-Powered Job Recommendation System using MERN Stack and Machine Learning.

## Project Overview
A web-based platform that analyzes candidate resumes and recommends suitable job opportunities using NLP and Machine Learning.

## Technology Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Python
- FastAPI
- Scikit-learn

## Main Modules
- User Authentication
- Candidate Profile Management
- Resume Upload and Parsing
- Job Listings
- ML-Based Job Recommendations
- Skill Gap Analysis
- Job Application Tracking
- Admin Dashboard

## Project Structure
- frontend: React application
- backend: Node.js and Express API
- ml-service: Python ML service
- dataset: Dataset files
- docs: Project documentation

## Project Status
Initial project structure created. Implementation is in progress.
