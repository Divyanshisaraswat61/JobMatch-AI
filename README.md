# JobMatch AI

AI-Powered Job Recommendation System using MERN Stack and Machine Learning.

## Technology Stack
- React.js
- Node.js and Express.js
- MongoDB
- Python and FastAPI
- Scikit-learn
- TF-IDF and Cosine Similarity
- PDF text extraction

## Features
- Candidate registration and login
- JWT authentication
- PDF resume upload
- Resume text extraction
- Job listings and search
- Resume-to-job similarity scoring
- Personalized job recommendations
- Skill gap hints

## Project Structure
- frontend: React application
- backend: Express REST API
- ml-service: Python ML API
- dataset: Sample data location
- docs: Project documentation

## Project Status
Working MVP implementation. Sample job data is used for demonstration.
