# JobMatch AI

### AI-Powered Job Recommendation System using MERN Stack and Machine Learning

## Project Overview
JobMatch AI is a web-based platform designed to analyze candidate resumes and recommend relevant job opportunities using Natural Language Processing (NLP) and Machine Learning.

## Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- ML Service: Python and FastAPI
- Machine Learning: Scikit-learn
- NLP: TF-IDF and Cosine Similarity

## Main Modules
- User Authentication
- Candidate Profile Management
- Resume Upload and Parsing
- Job Listings and Search
- ML-Based Job Recommendations
- Skill Gap Analysis
- Job Application Tracking
- Admin Dashboard

## Project Structure
- frontend: React application
- backend: Node.js and Express API
- ml-service: Python ML service
- dataset: Dataset files
- docs: Project documentation
